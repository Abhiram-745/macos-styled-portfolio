# Original interface artwork

These SVGs were drawn from simple geometric shapes for Abhiram Kakarla's portfolio adaptation. They replace the inherited Apple imagery. PNG exports in `../icons/` retain existing application import paths; `favicon.svg` supplies `app/favicon.ico`, and `monogram.svg` supplies the startup AK mark.

Interface glyphs are authored directly in `app/components/symbol.tsx`. They do not load SF Symbols or a symbol font. The legacy symbol names remain an internal component API.

The original desktop implementation and its attribution are documented in the root README. No licence is asserted for the upstream implementation.
